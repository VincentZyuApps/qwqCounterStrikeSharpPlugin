# CS2 进服指导

## 1. 启用开发者控制台

1. 打开 CS2，点击左上角齿轮进入 **设置**。
2. 在 **游戏** 分类中找到 **启用开发者控制台（~）**。
3. 将它设为 **是**。
4. 打开 **键盘/鼠标** 设置，找到“切换控制台”，绑定 <kbd>~</kbd> 或自己顺手的按键。
5. 回到游戏后，按刚才绑定的按键打开控制台。

## 2. 输入连接指令

在控制台粘贴以下指令，然后按 <kbd>Enter</kbd>：

```text
connect laoke.vincentzyu233.cn:60829
```

连接成功后会进入 VincentZyu233 CS2 私服的 Minecraft Cache 创意工坊地图。

## 3. 进服后可以做什么

- 在聊天框输入 `!ws` 选择武器皮肤、刀具、手套和探员。
- 输入 `!tpalist` 查看玩家编号，再用 `!tpa <玩家>` 或 `!tpahere <玩家>` 发起传送请求。
- 输入 `awa` 或 `qwq` 试试趣味聊天回应。
- 已装备刀时输入 `!drop` 或 `!takeknife` 与同队队友分享刀。
